# Contributing

Thanks for taking the time to contribute.

- **Bugs and ideas:** open an issue using one of the templates. For a bug,
  the smallest steps that reproduce it are the most useful thing you can add.
- **Pull requests:** for anything beyond a small fix, open an issue first so
  we can agree on the approach before you spend time on it.
- **Security issues:** never in a public issue — see [SECURITY.md](SECURITY.md).

## Nera repositories

Every Nera package (the `nera` generator, the CLI, the validator, the plugins
and themes) follows one shared guide: code style, tests, commit messages and
how releases work. Read it before opening a pull request:

**[Nera contributing guide](https://github.com/seebaermichi/nera/blob/main/CONTRIBUTING.md)**
